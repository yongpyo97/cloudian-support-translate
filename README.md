# Cloudian Support Translate

Windows x64 사용 안내

Cloudian 지원 메일을 번역해 Telegram으로 알립니다.
SMTP를 설정하면 Telegram에서 회신 초안을 확인한 뒤 이메일로 보낼 수 있습니다.

## 1. 처음 실행하기

1) ZIP을 쓰기 가능한 폴더에 풀고 Cloudian Support Translate.exe를 실행합니다.
   현재 버전은 Windows 앱의 제목 표시줄에서 확인할 수 있습니다.
2) Windows용 Codex 앱 또는 Codex CLI가 설치된 PC에서 Codex 번역의 [계정 연결]을
   눌러 로그인합니다. 로그인 후 [수신 메일 모델]과 [회신 메일 모델]을 각각 선택할 수 있습니다.
3) [계정 추가]에서 이메일 주소, IMAP 서버, 포트, 메일함과 비밀번호를 입력합니다.
   서버 주소는 메일 서비스가 제공한 값을 사용하세요. 기본 메일함은 INBOX,
   기본 IMAP 포트는 SSL/TLS 993입니다.
4) Telegram의 @BotFather에서 발급받은 봇 토큰을 입력합니다.
   개인 채팅에서는 먼저 봇과 대화를 시작한 뒤 [개인 채팅 찾기]를 이용하세요.
   그룹에서는 봇을 초대하고 [그룹 찾기]에서 대상 그룹을 선택하세요.
   Chat ID를 알고 있으면 직접 입력할 수도 있습니다.
5) [연결 테스트]로 Telegram을 확인한 뒤 [변경 적용]을 누릅니다.
   처음 확인할 때는 받은편지함에 남아 있는 읽지 않은 메일도 처리될 수 있습니다.

## 2. 메일 확인과 UID 찾기

- Telegram 알림에는 메일 제목과 수신 시각이 표시됩니다. 짧은 메일은 제목 아래
  인용문 화살표로 원문과 번역을 즉시 펼치거나 접을 수 있습니다. 긴 메일은
  [본문 파일 받기]를 누르면 TXT로 받습니다. 그룹에 요청한 파일은 그룹 구성원에게 표시됩니다.
- 이메일 계정 표에서 계정을 선택한 뒤 [UID 조회·재번역]을 누릅니다.
  [받은편지함]과 [저장된 UID]에서 수신 시각, 제목, UID를 확인할 수 있습니다.
  제목이나 케이스 번호로 검색하거나 [이전 메일 더 보기]로 목록을 늘릴 수 있습니다.
- [UID 복사]는 번호를 복사합니다. [선택 메일 재번역]은 번역을 다시 실행하여
  현재 설정된 Telegram 채팅에 알림을 보냅니다. 목록을 조회할 때는 메일의
  읽음 상태가 바뀌지 않습니다.

## 3. Telegram에서 메일 회신하기

1) 이메일 계정 [수정]에서 SMTP 서버와 포트를 입력하고 [변경 적용]을 누릅니다.
   기본 SMTP 포트는 SSL/TLS 465이며, 저장된 IMAP 계정과 비밀번호로 로그인합니다.
2) 상대방이 보낸 원본 메일의 Telegram 알림에 [답장]으로 회신 본문을 입력합니다.
   초안을 만드는 중이라는 상태가 표시됩니다. 한국어로 입력하면 다듬은 한국어,
   발송할 영어, 한국어 역번역을 확인할 수 있습니다.
3) 초안의 보내는 사람, 받는 사람, 본문을 확인합니다. [메일 보내기]는 SMTP 발송,
   [수정]은 새 초안 작성, [취소]는 초안 취소입니다. 수정할 때는 봇의 안내에
   새 본문 전체를 답장하세요. [수정 취소]로 기존 초안에 돌아갈 수 있습니다.
4) 발송 중에는 초안 아래에 진행 문구가 표시되고, 발송 뒤에도 초안과 첨부파일을 볼 수 있습니다.
   SMTP 서버가 회신을 접수하면 같은 메일을 발신 계정의 IMAP 보낸 편지함에 저장합니다.
   발송 실패, 접수 여부 미확인, 보낸 편지함 저장 실패는 Telegram에 각각 표시됩니다.

[회신 서명]에서 인사말과 서명을 각각 편집할 수 있습니다. [편집 완료] 후 메인 화면의
[변경 적용]을 누르면 새 초안에 반영됩니다. 비워 둔 항목은 추가되지 않습니다.
[회신 프롬프트]에서는 본문을 다듬고 번역할 때 쓸 지시문을 편집할 수 있습니다.

그룹 회신을 쓰려면 허용할 팀원이 그룹에서 /myid@봇아이디를 보낸 다음,
앱의 [회신 허용 사용자 선택]에서 팀원을 선택하고 [변경 적용]을 누르세요.
초안 작성자가 수정, 취소, 발송을 할 수 있습니다. 그룹의 알림과 초안은 구성원에게 보입니다.
그룹에서 /help@봇아이디를 보내면 봇 사용법을 확인할 수 있습니다.

## 4. 화면과 실행 설정

- 상단에서 Codex 사용 한도와 마지막 갱신 시각을 확인합니다. [새로고침]으로 다시 조회합니다.
- 테마 메뉴에서 시스템 설정, 다크 모드, 라이트 모드를 고릅니다.
  [변경 적용]을 누르면 선택한 모드가 저장됩니다.
- 화면 아래 [회사명 변경]에서 제목 앞에 붙일 이름을 편집합니다.
  빈칸으로 적용하면 Cloudian Support Translate로 표시됩니다.
- [창을 닫아도 트레이에서 실행]이나 [Windows 로그인 시 자동 시작]을 선택한 다음
  [변경 적용]을 누릅니다. 완전히 끄려면 Windows 트레이 메뉴의 [종료]를 선택하세요.

## 5. 업데이트와 문제 확인

- 업데이트할 때는 기존 앱을 트레이에서 종료한 뒤 새 EXE를 기존 설치 폴더의
  EXE와 교체합니다. 자동 시작에 이전 파일명이 등록돼 있으면 새 EXE를 기존 파일명으로
  바꾸어 교체할 수 있습니다. 같은 폴더의 settings.json, settings.sqlite3,
  settings.ui.json(회사명을 저장한 경우)을 유지하면 설정과 처리 기록을 이어서 씁니다.
- 연결이 안 되면 앱의 [로그 열기]로 실패한 단계를 확인하세요. 새 로그에는 메일 UID
  숫자가 기록되지 않으므로 UID가 필요할 때는 [UID 조회·재번역]을 사용하세요.
- 배포 ZIP에는 실행 파일과 이 안내서가 들어 있습니다. 개인 설정, 비밀번호,
  Telegram 토큰과 메일 기록은 사용 중인 설치 폴더에 저장됩니다.
